I use AWS to connect cloud concepts with practical server and network configuration.

## Focus areas

- EC2 provisioning, Linux server setup, and baseline hardening
- IAM and least-privilege decision-making
- VPC networking and Security Group access rules
- Regions, Availability Zones, Elastic IP, and shared-responsibility fundamentals

## Learning outcome

The lab helps me explain how identity, networking, and host configuration combine to reduce unnecessary exposure in a cloud environment.
