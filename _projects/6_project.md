I use a structured workflow for each vulnerability topic.

## Workflow
1. Understand the vulnerable behavior.
2. Reproduce it safely.
3. Document root cause and mitigation.
4. Re-test to confirm understanding.

## Topics covered
SQL Injection, XSS, CSRF, XXE, SSRF, auth flaws, access control, OAuth, and JWT.
