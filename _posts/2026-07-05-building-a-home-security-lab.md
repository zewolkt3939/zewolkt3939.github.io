I learn best by building systems myself. My home lab usually starts from a Linux base VM and expands with Docker services for web testing.

Current setup goals:

- Keep environments easy to reset
- Separate test targets from tooling
- Document every misconfiguration and fix

This process helps me improve troubleshooting speed and security intuition.
