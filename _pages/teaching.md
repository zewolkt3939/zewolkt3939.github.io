## Networking roadmap (CCNA)
OSI, TCP/IP, Ethernet, IPv4/IPv6, VLANs, Inter-VLAN routing, STP/RSTP, EtherChannel, OSPF, NAT, ACL, DHCP, DNS, QoS, SNMP, and wireless basics.

## Linux roadmap
Daily practice with Bash, SSH, permissions, systemd, package management, process control, storage, network configuration, services, firewall, and iptables.

## Cloud roadmap (AWS)
EC2, IAM, VPC, Security Groups, Elastic IP, regions, availability zones, and cloud security responsibility boundaries.

## Security roadmap
Network security, Linux security, web security, secure authentication/authorization design, encryption, PKI, VPN, reverse proxy security, and secure network design.

## SOC / Blue team roadmap
SIEM workflows using Wazuh and Elastic Stack, with ongoing study of Splunk and Sentinel concepts for monitoring and investigation.
